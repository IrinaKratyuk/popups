# Правила проекта

## Библиотека компонентов

- «Библиотека» — это [MarieSmi/ui-kit](https://github.com/MarieSmi/ui-kit). Локальная копия находится в соседней папке `../ui-kit`, а [каталог компонентов](https://mariesmi.github.io/ui-kit/catalog/) показывает их внешний вид и состояния.
- Перед созданием или изменением элемента интерфейса сначала найди подходящий компонент в библиотеке и сверь его внешний вид, состояния и поведение с задачей. Используй исходный код компонента из ui-kit.
- Если нужный компонент не найден, есть расхождения с задачей или нужно допущение, сообщи об этом пользователю до изменений. Не создавай свою замену и не выбирай, как отступить от библиотечного компонента, без решения пользователя.

## Настройки страниц

- Для всех страниц настройки в конструкторе и в карточке сайта на вкладке «Параметры» должны совпадать. Используй общие поля и значения по умолчанию. Адрес по умолчанию в конструкторе показывается как подсказка, а в карточке сайта — как заполненное значение с тем же текстом.

## Команды пользователя

- **«ссылку»** — прислать локальную ссылку на демо. Демо запускается через `preview_start` с конфигурацией `components` из `.Codex/launch.json` (по умолчанию http://localhost:5173/, при занятом порте — тот, что вернул сервер). Если сервер не запущен — запустить и дать ссылку.
- **«отправь»** — закоммитить все последние изменения в проекте и залить их: сначала забрать новые коммиты из `irina/main` (`git pull --rebase`), затем `git push` в remote `irina` (IrinaKratyuk/popups). В `origin` (MarieSmi/popups) не пушить.
