# Попапы — прототип

Интерактивный прототип попапов в окне конструктора Saby. Сцена 1600×900 и вспомогательная панель справа.

## Ссылки

- Демо (GitHub Pages): https://mariesmi.github.io/popups/
- Репозиторий (публичный): https://github.com/MarieSmi/popups
- Разработка макета: https://tensor.saby.ru/opendoc.html?guid=01a10b9e-d00c-7be9-9307-91f4f08a3298&client=3
- Макет: будет добавлен

## Состав

- Рамка демо (шапка, сцена, вспомогательная панель) — компонент `demo-frame` из [ui-kit](https://github.com/MarieSmi/ui-kit), подключён с jsDelivr по тегу `1.11.0`.
- Шапка конструктора — компонент [Builder-components](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=5-28058), узел `5:28058`. Кнопки только с ховером, без действий по клику.
- Правый сайдбар — компонент [Создание страниц и окон](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=148-15451), узел `148:15451`: вписан в страницу, по умолчанию «Магазин»; «Данные»; окно «Параметры сайта».
- Виджет каталога — [узел `2547:84548`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2547-84548): ставится по клику на «Каталог» в магазине вместо пустой секции; каталог пропадает из магазина, появляется страница «Карточка товара». Выделение и тулбар — `widget` и `toolbar` из ui-kit.
- Левый сайдбар со списком страниц — компонент [Builder-components](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=5-28393), узел `5:28393`. Режим (вписан или линии) запоминается в браузере, страницы при обновлении возвращаются к исходным.
- Новая страница — после сохранения окна открывается пустая секция: для режимов «На странице» и «Страница и окно» — [узел `2406:28596`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2406-28596), для «В окне» — [узел `2167:87296`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2167-87296). Кнопка «+ секция» — [узел `4590:7239`](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=4590-7239), пока только с ховером.
- Сценарии на вспомогательной панели — состояния страницы. «Создание окна с товаром» — исходное состояние: страница «Меню» с каталогом и подсказка на плюсе. Пункт «Новая страница» в группе «Работа с окнами/страницами» с вложенными вариантами («На странице», «В окне», «Страница и окно») сразу открывает новую страницу в этом режиме. Панель следует за открытой страницей: при выборе в списке и сохранении окна отмечается её сценарий. Остальные сценарии группы «Работа с окнами/страницами» скрыты.
- Переключатель окно-страница — [узел `2516:32636`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2516-32636): в режиме «Страница и окно» стоит в шапке справа от адаптива с отступом 12. «Страница» (по умолчанию) — адаптив активен, «Окно» — вид как у «В окне», адаптив неактивен.
- Настройки окна — «Назад» в тулбаре секции выделяет окно, шестерёнка в его тулбаре открывает [узел `2489:24408`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2489-24408) в виде `.pe` из ui-kit. Размер с меню единиц, оформление, крестики и чипсы — `PropertyEditor` из ui-kit, отступы по осям и сторонам — как в STV. Правки сразу видны на холсте; клик по «Положение» пока не работает.
- Окно «Фон» — перенесено из `interface-prototype` (Figma `16385:63244`): открывается из строк «Фон» и «Затемнение сайта» настроек окна и по команде «Фон» в тулбаре окна и секции (под командой, зазор 4px). У секции фон по умолчанию не задан: пустая плашка, HEX пустой, прозрачность 0; фон секции хранится у страницы. HEX и прозрачность, заготовленные цвета и градиенты, картинки (`assets/img/bg/`) и экран «Картинка» с ползунками. Заготовленный цвет или градиент применяется и закрывает окно, картинка оставляет его открытым; у затемнения заготовленный цвет сохраняет прозрачность. Пока открыты настройки окна, правки идут в их черновик: их сохраняет ✓ настроек, отменяет ✕; без настроек правка из тулбара применяется сразу. На холсте конструктора затемнения нет, поэтому его значение видно только в строке редактора.
- Карточка товара — по клику в магазине встаёт в секцию новой страницы или окна вместо пустой ячейки, «Назад» поднимает на уровень секции, [узел `2695:72015`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2695-72015). Из магазина виджет пропадает, удаление возвращает его. Содержимое — рендер макета, выделение и тулбар — `widget` и `toolbar` из ui-kit.
- Шрифты Inter, cbuc-icons, cbuc-icons24 и Accordion-Font — в `assets/fonts`, тоже из interface-prototype.
- Середина — сайт в конструкторе, [узел `2547:63290`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2547-63290). Ховер виджетов и команды пустого виджета — компонент `widget` из ui-kit. Шрифт сайта Montserrat подключён с Google Fonts.

## Запуск

Без сборки и зависимостей:

```bash
node .claude/serve.js
```

Откроется на http://localhost:5173.

## Публикация

Сайт собирается из ветки `main`, папка `/ (root)`. Пуш в `main` обновляет его за 1–2 минуты.
