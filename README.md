# Попапы — прототип

Интерактивный прототип попапов в окне конструктора Saby. Сцена 1600×900 и вспомогательная панель справа.

## Ссылки

- Демо (GitHub Pages): https://irinakratyuk.github.io/popups/
- Репозиторий (публичный): https://github.com/IrinaKratyuk/popups

- Концептуальное описание: [docs/concept/index.md](docs/concept/index.md)

## Состав

- Рамка демо (шапка, сцена, вспомогательная панель) — компонент `demo-frame` из [ui-kit](https://github.com/MarieSmi/ui-kit), подключён с jsDelivr по тегу `1.13.0`.
- Шапка конструктора — компонент [Builder-components](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=5-28058), узел `5:28058`. Кнопки только с ховером, без действий по клику.
- Правый сайдбар — компонент [Создание страниц и окон](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=148-15451), узел `148:15451`: вписан в страницу, по умолчанию «Магазин»; «Данные»; окно «Параметры сайта».
- Виджет каталога — [узел `2547:84548`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2547-84548): ставится по клику на «Каталог» в магазине в зону контента секции вместо пустой ячейки; каталог пропадает из магазина, появляется страница «Карточка товара». Выделение и тулбар — `widget` и `toolbar` из ui-kit.
- Левый сайдбар со списком страниц — компонент [Builder-components](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=5-28393), узел `5:28393`. Режим (вписан или линии) запоминается в браузере, страницы при обновлении возвращаются к исходным.
- Новая страница — после сохранения окна открывается пустая секция: для режимов «На странице» и «Страница и окно» — [узел `2406:28596`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2406-28596), для «В окне» — [узел `2167:87296`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2167-87296). Кнопка «+ секция» — [узел `4590:7239`](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=4590-7239), пока только с ховером.
- Панель настроек обратной связи — [узел `2648:45307`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2648-45307): открывается шестерёнкой виджета обратной связи в сценарии «Виджет добавлен» и на странице «Обратная связь». Настраивает вид и положение плавающего виджета; способ вставки выбирается при добавлении, в окне настройки вставки. Правки видны только в панели, галочка применяет их к сайту, крестик и Esc отменяют. Клик по кнопке в панели открывает поверх неё общее окно настроек кнопки, его правки сохраняются вместе с панелью. «Основной стиль», «+» у полей, «всегда» и вкладки «Интеграция» и «Настройки» пока только с ховером. Форма — общий шаблон, палитры — PropertyEditor (если палитра не умещается в панели, она смещается влево), положение плавающей кнопки — свой редактор кнопки на 4 угла (положение окна задаёт общий редактор на 9 ячеек); «Показывать: Окно» после сохранения ставит вместо кнопки плашку в том же углу: разворачивает её только «Открыть» в тулбаре: окно в том же виде, что на странице «Обратная связь». «Закрыть», крестик и клик мимо сворачивают, чтобы окно не мешало править страницу. В тулбаре: «Назад», «Открыть / Закрыть», настройки, удаление, «Ещё»; фон за панелью не затеняется, правый столбец — картинка из макета.
- Сценарии на вспомогательной панели — состояния страницы. «Создание окна с товаром» — исходное состояние: страница «Меню» с каталогом и подсказка на плюсе, в группе «Работа с каталогом» подсказки на плюсе нет. «Связь кнопки с окном» — продолжение: окно «Товар» с карточкой товара уже есть в списке страниц, на «Меню» после каталога — секция с кнопкой «Товар», [узел `2863:49443`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2863-49443). Кнопка, виджет и тулбар — из ui-kit, команды тулбара и самой связи пока нет: только ховер. Пункт «Новая страница» в группе «Работа с окнами/страницами» с вложенными вариантами («На странице», «В окне», «Страница и окно») сразу открывает новую страницу в этом режиме. Панель следует за открытой страницей: при выборе в списке и сохранении окна отмечается её сценарий. Остальные сценарии группы «Работа с окнами/страницами» скрыты.
- Сценарии группы «Внешние виджеты»: «Добавление внешнего виджета» — исходное состояние; «Виджет добавлен» с вариантами «Плавающая кнопка» и «В секции»; «Обратная связь» — открытая страница с формой, варианты — режимы открытия: «На странице», «В окне», «Страница и окно»; «Связь кнопки с окном» — кнопка на странице с открытыми настройками. Макетов на эту кнопку и форму в секции нет: кнопка — та же, что в «Работе с окнами», форма — та же, что в окне. Удаление виджета возвращает к добавлению.
- Сценарий «Добавление внешнего виджета» — [узел `2616:31125`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2616-31125): прототип открывается на нём. Дубль состояния с каталогом: открыта «Меню», страница «Карточка товара» уже в списке. В магазине вместо «Расширенных» группа «Внешние»: «Обратная связь» с подсказкой клика и «Онлайн-запись» — она только показана, без клика и ховера. Клик по «Обратной связи» открывает окно выбора варианта ([узел `27261:169142`](https://www.figma.com/design/G3QPR5r3X5ox6DmPwj6rJ7/?node-id=27261-169142), без галочки), на это время пин с виджета пропадает. Выбор плашки открывает вместо него окно настройки вставки ([узел `27261:169213`](https://www.figma.com/design/G3QPR5r3X5ox6DmPwj6rJ7/?node-id=27261-169213)): превью варианта и «Расположение на сайте» — меню «Плавающее» или «В теле страницы», тот же компонент, что «Открывать»; клик по превью возвращает к выбору, галочка вставляет. Плавающий виджет ставит плавающую кнопку ([узел `2648:62449`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2648-62449)): глобальный виджет в оформлении success, как шапка и подвал: поверх страницы, не прокручивается, видна на всех страницах, кроме вида «в окне», тулбар и настройки — общие с секцией с кнопкой, но без «Назад», «Удалить» убирает её и возвращает пин. Вместе с кнопкой в списке появляется страница «Обратная связь» — окно по логике «В окне» с формой из [узла `2654:44316`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2654-44316), 424×400, без крестика окна: у формы свой; удаляется вместе с кнопкой.
- Окно внешних виджетов — [узел `2894:48645`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2894-48645): открывается по центру по клику на внешний виджет в магазине, закрывается крестиком, Esc и кликом мимо. Плашки — превью магазина `.rs-w__pv` с тем же ховером (рамка и плюс), на первой — пин; остальные плашки и «По умолчанию» без действий. Варианты «Онлайн-записи» — заглушка: в макете есть только «Обратная связь».
- Переключатель окно-страница — [узел `2516:32636`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2516-32636): в режиме «Страница и окно» стоит в шапке справа от адаптива с отступом 12. «Страница» (по умолчанию) — адаптив активен, «Окно» — вид как у «В окне», адаптив неактивен.
- Настройки окна — «Назад» в тулбаре секции выделяет окно, шестерёнка в его тулбаре открывает [узел `2489:24408`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2489-24408) в виде `.pe` из ui-kit. Размер с меню единиц, оформление, крестики и чипсы — `PropertyEditor` из ui-kit, отступы по осям и сторонам — как в STV. Правки сразу видны на холсте. Редактор положения — [узел `2489:25551`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2489-25551): переключатель «От элемента» и «На экране» пока убран, показывается сетка «На экране». Метка — «Положение», смещения и кнопки «По центру» из макета нет. Внутри пока только ховер: выбор положения на холст не влияет.
- Настройки секции — шестерёнка в тулбаре секции открывает [узел `17197:204679`](https://www.figma.com/design/rZBslLyyMuhvoFziHj5SZi/?node-id=17197-204679) в виде `.pe` из ui-kit по левому верхнему углу секции. Название меняется, фон — чипса: пока он не задан, строки нет. Ширина контента, отступы и фон сразу видны на холсте, ✓ сохраняет их в страницу, ✕ и Esc отменяют. В полях отступов — фактические значения секции. В макете есть только ширина «Узкая», «Широкая» и «Во всю ширину» — допущение. «Действие» и «Закрепить снизу» пока без действий.
- Окно «Фон» — перенесено из `interface-prototype` (Figma `16385:63244`): открывается из строк «Фон» и «Затемнение сайта» настроек окна и по команде «Фон» в тулбаре окна и секции (под командой, зазор 4px). У секции фон по умолчанию не задан: пустая плашка, HEX пустой, прозрачность 0; фон секции хранится у страницы. HEX и прозрачность, заготовленные цвета и градиенты, картинки (`assets/img/bg/`) и экран «Картинка» с ползунками. Заготовленный цвет или градиент применяется и закрывает окно, картинка оставляет его открытым; у затемнения заготовленный цвет сохраняет прозрачность. Правка применяется к окну страницы сразу. На холсте конструктора затемнения нет, поэтому его значение видно только в строке редактора.
- Карточка товара — по клику в магазине (там, где это можно сделать, на виджете стоит точка клика) встаёт в зону контента секции новой страницы или окна вместо пустой ячейки, «Назад» поднимает на уровень секции, [узел `2695:72015`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2695-72015). Из магазина виджет пропадает, удаление возвращает его. Содержимое — рендер макета, выделение и тулбар — `widget` и `toolbar` из ui-kit.
- Настройки кнопки — [узел `2863:49501`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2863-49501) в виде `.pe` из ui-kit: открываются из тулбара кнопки шестерёнкой, в сценарии сразу открыты, слева от кнопки. Текст сразу виден на кнопке, ✓ сохраняет, ✕ и Esc отменяют. «действие» открывает [меню](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2349-60397) по шагам: наведение на «Открыть страницу сайта» раскрывает список страниц, с подсказками на шагах. После выбора строка — как в [узле `2355:71525`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2355-71525), со свойством «Открывать» и редактором положения. Остальные строки, чипсы, «Пролистать к блоку», «Все действия» пока только с ховером. Команда «Действие» в тулбаре — глиф `EB7E`, только с ховером. Выделение с кнопки кликом мимо не снимается.
- Свойство «Открывать» — одно на все окна: настройки страницы и настройки кнопки. Разметка в `<template id="openMode">`, стили `.open-mode*`, поведение в `openModeFill`. Правка меняет его везде, окно задаёт только список вариантов: у страницы «В новом окне», «На странице», «В окне и на странице», у кнопки первые два. Меню — [узел `2406:20980`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2406-20980).
- Редактор положения — один на все окна: настройки окна и настройки кнопки. Разметка в `<template id="posEditor">`, стили `.pos*`, поведение в `posEditorFill` и `posEditorRender`. Правка редактора меняет его везде, отдельных копий нет.
- Перетаскивание — окна настроек (`.pe`: страницы, окна, секции, кнопки) двигаются за шапку и не выходят за края сцены, при следующем открытии встают на обычное место. Общий код — `peDraggable`.
- Окна и меню — одновременно открыто только одно: «Параметры сайта», меню «⋮», окно страницы, настройки окна, настройки секции, настройки кнопки, окно «Фон». Новое закрывает прежнее, несохранённые правки в нём отменяются. «Фон» из строки настроек встаёт вместо них, правки настроек при этом сохраняются. С родителем остаются только меню, которые без него не работают: режим открытия, меню и палитры `PropertyEditor`.
- Шрифты Inter, cbuc-icons, cbuc-icons24 и Accordion-Font — в `assets/fonts`, тоже из interface-prototype.
- Ширина контента — одна на все секции сайта: боковой отступ `--site-gutter` (32), на всю ширину только баннер. Заглушка пустой секции с пятью командами тоже одна: разметка в `<template id="siteEmptyContent">`, стили `.site-empty`, вставляется в каждый `.site-empty`.
- Виджет «Секция» — всегда один вид: пустое состояние из пяти команд (`siteEmptyContent`) и один набор в тулбаре: «Фон», «Закрепить», «Настройки», «Удалить», «Ещё» (`<template id="sectionCmds">`, вставляется в каждый `[data-section-cmds]`). Новая секция собирается только из них. «Назад» есть лишь у секции внутри окна: поднимает на уровень окна. «Фон» открывает окно «Фон», «Настройки» — настройки секции, у всех секций одинаково (`SEC_NODES`), правка идёт в секцию, из которой открыто окно. «Закрепить», «Удалить» и «Ещё» пока только с ховером.
- Страницы сайта — «Главная»: шапка, баннер, «О нас»; «Меню»: шапка, каталог; «Карточка товара»: шапка, карточка товара. Секции сценариев (кнопка, пустая секция) встают на «Меню» после каталога. Клик по «Каталогу» в магазине на «Главной» открывает «Меню» и ставит его туда.
- Форма «Обратная связь» — [узел `2654:44316`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2654-44316), живая вёрстка: поля и чекбоксы — `input` и `checkbox` из ui-kit. Своего фона нет, крестик только в окне. В окне виджет занимает всю секцию, отступы — внутри формы; в секции на странице — по зоне контента. Содержимое статично и настраивается в панели: клик по полям и чекбоксам только выделяет виджет, в панели живой только заголовок. Клик по виджету в магазине и точка клика есть только на странице «Меню». После добавления виджета нет в магазине на всех страницах, удаление возвращает его. Страница создаётся автоматически, поэтому удалить с неё виджет и секцию нельзя (у страниц про товар удаление есть).
- Выделение — при переключении страницы снимается со всех виджетов, на открытой странице оно появляется только кликом. Родитель выделенного виджета получает `.wg--level-2` из ui-kit (`siteParentsSync`, общее правило для секций): только пунктир цветом акцента, при наведении на самого родителя рамка сплошная. Кнопки «+ секция» есть лишь у активной секции.
- Футер — [узел `2899:48815`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2899-48815): один шаблон на все страницы, кроме вида «в окне». Всегда последний, идёт сразу за последней секцией, ховер зелёный, как у шапки.
- Середина — сайт в конструкторе, [узел `2547:63290`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2547-63290). Ховер виджетов и команды пустого виджета — компонент `widget` из ui-kit. Шрифт сайта Montserrat подключён с Google Fonts.

## Точки продаж

В сценарии «Добавление каталога» каталога на сайте ещё нет. Добавление каталога включает переменные «Точки продаж» и «Текущая точка» в панели данных. Подтверждение выбора в списке сразу сохраняет точки в параметрах сайта; дополнительное подтверждение окна каталога для этого не требуется. В каждом узле компании есть по две демонстрационные точки с вымышленными названиями.

«Настройки» в правом тулбаре открывают параметры сайта по макету `2547:76412`. Если на сайте есть каталог, под SEO показаны точки продаж и их прайсы.

Для проверки добавления выберите сценарий «Добавление каталога», затем нажмите на превью виджета «Каталог» в магазине. Откроется окно «Точки продаж»: плюс открывает выбор точек с поиском, ✓ подтверждает выбор, затем ✓ окна сохраняет настройки. Крестик и Esc отменяют черновик. Шестерёнка каталога позволяет снова открыть это окно. В параметрах сайта можно добавлять и удалять точки, выбирать основную и менять прайс по клику на его название.

Данные демонстрационные, из сценария Figma `2547:63896`. Как и страницы прототипа, настройки точек сохраняются в текущем сеансе и сбрасываются при перезагрузке.

В «Авторской кухне» три блюда без подразделов. После каталога добавлена секция «Что такое Мили» по макету `2824:74343`, изображение — `assets/img/site/about.png`.

## Запуск

Настройки страницы: меню «Доступ» выбирает «Без авторизации» или «Только авторизованным». В SEO кнопка «Описание» раскрывает многострочное поле; доступ и описание сохраняются в странице до перезагрузки прототипа. Заголовок «Открывать» выровнен по тексту пунктов меню.

Тулбары виджетов при прокрутке остаются поверх шапки конструктора с минимальным отступом 6 px от верха сцены. В магазине «Каталог» расположен перед «Карточкой товара». Панель выбора точек продаж соответствует узлу Figma `2596:108384`; графика чекбоксов и кнопки закрытия сохранена в `assets/img/sales-*.svg`.

Без сборки и зависимостей:

```bash
node .claude/serve.js
```

Откроется на http://localhost:5173.

## Публикация

Сайт собирается из ветки `main`, папка `/ (root)`. Пуш в `main` обновляет его за 1–2 минуты.
