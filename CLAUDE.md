# Правила проекта

## Команды пользователя

- **«ссылку»** — прислать локальную ссылку на демо. Демо запускается через `preview_start` с конфигурацией `components` из `.claude/launch.json` (по умолчанию http://localhost:5173/, при занятом порте — тот, что вернул сервер). Если сервер не запущен — запустить и дать ссылку.
- **«отправь»** — закоммитить все последние изменения в проекте и залить их: сначала забрать новые коммиты из `irina/main` (`git pull --rebase`), затем `git push` в remote `irina` (IrinaKratyuk/popups). В `origin` (MarieSmi/popups) не пушить.
